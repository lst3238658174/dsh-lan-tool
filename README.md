# dsh‑lan‑tool
DSH 局域网一体化工具，Windows批处理脚本，利用系统 `portproxy` 实现 DSH Web局域网访问。

> ⚠️安全警告：DSH存在远程代码执行风险，**仅限家庭内网使用，严禁暴露公网**。
> portproxy 是 Windows持久系统规则，重启电脑不会自动清除，使用完毕务必清理规则。

## 功能特性
- 管理员权限自动检测
- 自动探测本机局域网IP，单网卡环境无需手动配置IP
- 一键开启/关闭局域网端口转发(portproxy)
- 自动创建/清理 Windows防火墙放行规则
- Node/npm环境检测，可选开启Node.js静默自动安装
- DSH全局安装检测，缺失时交互式自动执行npm全局安装dsh
- NPM镜像源切换：一键切换淘宝国内镜像 / 还原官方源，解决npm下载超时
- DSH版本检测：本地缓存版本与NPM源最新版本比对，查看是否需要升级
- DSH一键更新：版本相同时自动跳过，内置国内镜像加速拉取最新版本
- 分层菜单设计：常用功能放在一级主菜单，版本/镜像设置收纳二级进阶子菜单
- 一键完整状态自检
- 一键拉起 DSH Web独立窗口服务
- 一键终止全部Node/DSH残留进程
- 退出前残留规则安全校验，自动清理持久转发
- 移除全部Unicode特殊符号，原生兼容ANSI编码，无中文乱码
- 纯bat脚本，无需第三方依赖

## 环境要求
- Windows10 / Windows11
- Node.js LTS（自带npm）
> 脚本支持可选开启Node自动静默安装；安装Node后**必须重启脚本**环境变量才生效。
- 端口转发、防火墙操作**需要管理员权限**

## 使用方法
1. 在Release下载 `dsh_tool.bat`
2. **右键 → 以管理员身份运行 dsh_tool.bat**

> 多网卡/VPN/WSL环境，如果自动识别IP错误，可以脚本顶部手动强制指定IP：
```batch
set LOCAL_IP=192.168.1.19
```

### 菜单简要说明
#### 一级主菜单（日常高频操作）
1. 创建端口转发规则 — 创建portproxy转发+防火墙放行，局域网其他设备可访问DSH服务
2. 查看本机现有端口转发 — 查看系统全部portproxy持久转发规则
3. 删除全部端口转发规则 — 清空本机所有portproxy转发，**退出前务必执行**
4. 一键配置DSH局域网隧道 — 快速完成DSH局域网整套访问配置
5. 启动 DSH(npx)服务【新开独立窗口】— 新开CMD窗口后台运行DSH，不阻塞主脚本
6. 终止全部 Node / DSH 进程 — 杀掉本机残留node、DSH窗口，释放占用端口
7. 重新执行环境自检 — 批量校验管理员权限、Node、npx、服务端口状态
8. 进入进阶设置子菜单（版本检测/更新/NPM镜像管理）
9. 退出脚本 — 自动清空转发规则后关闭程序

#### 二级进阶设置子菜单（低频配置功能）
1. 检测 DSH 版本信息 — 获取本地运行版本与线上npm最新版本，自动比对提示更新
2. 更新 DSH 到最新版本 — 版本一致自动跳过，新版本使用国内镜像加速拉取
3. NPM镜像源管理
   - 切换 npmmirror国内镜像
   - 恢复官方npm源
   - 查看当前生效镜像地址
   - 一键清理npm/npx缓存
0. 返回一级主菜单

## 重要注意事项
1. **必须管理员运行**，否则端口转发、防火墙配置会失败。
2. Windows `portproxy` 规则属于系统持久规则，**电脑重启不会自动删除，用完一定要清理转发规则**。
3. Node.js自动安装完成后，**必须关闭当前脚本窗口重新打开**，环境变量才会生效。
4. DSH仅建议内网访问，**不要直接暴露到公网，存在远程代码执行安全风险**。
5. 脚本编码必须保存为 ANSI，禁止使用UTF‑8直接保存，否则会出现中文乱码、字符丢失报错。
6. 更新DSH时无进度输出属于正常现象，等待1-3分钟即可；卡住可进入镜像管理菜单清理缓存重试。

## 常见问题
### Q：启动更新一直卡住不动？
A：npx本身没有下载进度输出，属于假卡死。优先切换国内NPM镜像；进入进阶设置-NPM镜像管理执行缓存清理，或手动执行 `npm cache clean --force` 后重试。

### Q：Node安装完脚本还是识别不到？
A：Node安装后系统环境变量不会在已打开的CMD窗口即时生效，**完全关闭脚本窗口重新双击运行即可**。

### Q：其他设备访问不了DSH网页？
1. 确认脚本是以管理员身份运行；
2. 确认已经执行创建端口转发规则；
3. 确认本机防火墙已经放行；
4. 检查本机自动识别局域网IP是否正确，多网卡环境手动指定`LOCAL_IP`变量。

### Q：重装系统/换电脑，端口转发规则会消失吗？
A：portproxy规则保存在系统注册表，重装系统会清除；同系统重启电脑规则不会消失，使用结束务必手动删除转发。

### Q：脚本保存后中文乱码？
A：脚本编码需设置为ANSI，记事本另存为时编码选择ANSI，Notepad++使用「编码-转为ANSI」后保存。
